# AstrAI Skills

> AstrAI-specific skills for managing the `.ai/` operating layer. For development workflows, see `.ai/skills/dev/` (Superpowers skills).

## Available Skills

| Skill | Path | Purpose |
|-------|------|---------|
| Startup | `startup/SKILL.md` | Mandatory startup sequence for AI agents |
| Project Bootstrap | `project-bootstrap/SKILL.md` | Set up AstrAI in a project |
| Memory Update | `memory-update/SKILL.md` | Update durable project memory |
| Handoff | `handoff/SKILL.md` | Produce clean handoff documents |
| Skill Bridge | `skill-bridge/SKILL.md` | Route dev tasks to Superpowers skills |
| Dispatcher Maintenance | `dispatcher-maintenance/SKILL.md` | Maintain AstrAI dispatcher files |
| Huddle | `huddle/SKILL.md` | Persistent, talk-only architectural conversation mode |

## When to Use AstrAI Skills

Use these skills for AstrAI-specific operations (startup, bootstrapping, memory management, handoffs). For general development workflows (planning, implementing, debugging, reviewing), use the Superpowers skills under `.ai/skills/dev/`.
