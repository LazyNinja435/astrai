# Skill: Handoff

## Purpose

Produce a clean, complete handoff document when finishing work. Ensures the next agent or developer can pick up where you left off.

## When to Use

- Before declaring a task complete
- When switching contexts away from the current task
- Before merging a branch

## Required Inputs

- Completed work summary
- Changed files list
- Test results
- Any open issues or risks

## Workflow

1. Summarize what was done in 2-3 sentences
2. List all files changed with brief descriptions
3. Report test results (passing, any known issues)
4. Note anything NOT done with reasons
5. List risks, caveats, and open questions
6. Document next steps
7. Use `.ai/templates/handoff.template.md`

## Output

A completed handoff document.

## Forbidden

- Handing off broken code
- Omitting known issues or risks
- Using vague descriptions
