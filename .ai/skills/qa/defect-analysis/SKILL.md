# Skill: Defect Analysis

## Purpose

Analyze defects to identify patterns, root causes, and systemic improvements. Goes beyond fixing individual bugs to improving quality processes.

## When to Use

- After a bug is fixed and documented
- During retrospective or quality review
- When similar bugs keep occurring

## Required Inputs

- Defect reports or bug database
- Relevant codebase context

## Workflow

1. Review the defect report
2. Identify root cause category: requirements gap, design flaw, coding error, testing gap, environment issue
3. Check for similar defects or patterns
4. Propose systemic improvements to prevent recurrence
5. Document using `.ai/templates/defect-report.template.md`

## Output

Defect analysis with root cause category, pattern identification, and prevention recommendations.

## Forbidden

- Blaming individuals
- Treating every defect as isolated without looking for patterns
- Proposing fixes that don't address root cause
