# Skill: README Authoring

## Purpose

Write and maintain high-quality README files for projects, packages, or modules. Ensures documentation is clear, comprehensive, and useful.

## When to Use

- Creating a new project README
- Updating an existing README
- User asks for documentation help

## Required Inputs

- Project context, purpose, and tech stack
- Target audience (developers, users, contributors)

## Workflow

1. Identify the target audience
2. Structure: title, tagline, purpose, quick start, documentation links, license
3. Write in clear, plain language
4. Include working examples for setup and usage
5. Verify all instructions work by following them
6. Cross-reference related documentation

## Output

A complete, verified README file.

## Forbidden

- Writing setup instructions without testing them
- Using technical jargon without explanation
- Creating READMEs with broken links or outdated info
