# README Updates

## Rule: Keep README Current

The project README must reflect the current state of the project. Update it when:
- Project structure changes
- New features are added
- Setup instructions change
- Dependencies change

## Rule: README Structure

- Project name and tagline at the top
- What the project does (one paragraph)
- Quick start or installation instructions
- Key documentation links
- License information

## Rule: Up-to-Date Instructions

Setup, build, and run instructions in the README must be verified to work after any change that affects them.
