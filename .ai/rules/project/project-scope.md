# Project Scope

## Rule: Stay Within Project Scope

Do not make changes outside the project repository without explicit permission.

**In scope:**
- Files within the project root
- `.ai/` directory and contents
- Any file tracked in version control

**Out of scope (without explicit permission):**
- System files outside the project root
- Global package installations
- Files in other repositories
- Production environments

## Rule: Respect Declared Boundaries

Read `.ai/memory/constraints.md` before making significant changes. If a constraint says "must not," do not do it.
