# Protocol: Automation Planning Flow

## Purpose

Plan test automation approach.

## Trigger

Test strategy is defined and automation is needed.

## Flow

```
Test Strategy Defined
    │
    ▼
[1] Candidate Selection → High-frequency, high-risk tests
    │
    ▼
[2] Tool Selection → Compatible with project stack
    │
    ▼
[3] Plan → Skill: qa/automation-planning
    │
    ▼
[4] Prioritize → By ROI
    │
    ▼
[5] Implementation → Automation Engineer agent
```
