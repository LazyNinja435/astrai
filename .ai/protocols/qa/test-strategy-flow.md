# Protocol: Test Strategy Flow

## Purpose

Define test strategy for a feature or release.

## Trigger

New feature or release planning.

## Flow

```
Feature/Release Defined
    │
    ▼
[1] Risk Assessment → What could go wrong?
    │
    ▼
[2] Strategy → Skill: qa/test-strategy
    │
    ▼
[3] Test Design → Skill: qa/test-case-design
    │
    ▼
[4] Automation Plan → Skill: qa/automation-planning (if applicable)
```
