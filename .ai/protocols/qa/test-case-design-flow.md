# Protocol: Test Case Design Flow

## Purpose

Design test cases from requirements and acceptance criteria.

## Trigger

Requirements with acceptance criteria are ready.

## Flow

```
Requirements Ready
    │
    ▼
[1] Review → Acceptance criteria
    │
    ▼
[2] Design → Skill: qa/test-case-design
    │          Template: test-case.template.md
    │
    ▼
[3] Review → Coverage review
    │          Happy path, errors, edge cases, boundaries
    │
    ▼
[4] Prioritize → By risk and business value
```
