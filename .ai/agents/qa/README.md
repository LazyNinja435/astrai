# QA Agents

> Agents for quality assurance: test strategy, test design, automation, and defect analysis.

## Available Agents

| Agent | Path | Purpose |
|-------|------|---------|
| QA Architect | `qa-architect.md` | Design test strategy |
| Test Designer | `test-designer.md` | Design test cases |
| Automation Engineer | `automation-engineer.md` | Implement test automation |
| Defect Analyst | `defect-analyst.md` | Analyze defects for patterns |

## When to Delegate

Do not delegate when the main agent can complete the task directly.
