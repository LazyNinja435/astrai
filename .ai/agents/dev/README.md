# Dev Agents

> Agents for development tasks. Follow Superpowers skills under `.ai/skills/dev/`.

## Available Agents

| Agent | Path | Purpose |
|-------|------|---------|
| Architect | `architect.md` | Design system architecture |
| Implementer | `implementer.md` | Write code per plan |
| Reviewer | `reviewer.md` | Review code for issues |
| Debugger | `debugger.md` | Diagnose and fix bugs |

## When to Delegate

- **Architect**: When the task requires system-level design decisions beyond a single file
- **Implementer**: When a plan step is ready for code execution
- **Reviewer**: When code needs independent review before merge
- **Debugger**: When a bug requires systematic investigation

## Important

Do not delegate to these agents when the main agent can complete the task directly. Delegation adds overhead — use it only when the task benefits from specialization.
